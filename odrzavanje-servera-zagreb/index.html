Redovito održavanje smanjuje hitne intervencije i iznenadne troškove

Većina kritičnih serverskih problema nije iznenađenje. Pun disk, istekli certifikati, neispravni backup zadaci i zastarjela ažuriranja su simptomi zanemarenog održavanja. Redoviti pregledi otkrivaju ove probleme prije nego uzrokuju zastoj.

Što provjeravamo redovito

Stanje diskova i RAID polja, uspješnost backup zadataka, Windows ažuriranja i sigurnosne zakrpe, Active Directory replikaciju, DNS i DHCP ispravnost, istek certifikata, performanse procesora i memorije te logove s greškama i upozorenjima.

Tipični scenariji koje sprječavamo

Server koji se ne može pokrenuti jer je disk pun logovima. Backup koji već mjesecima ne radi jer je istekla lozinka servisnog računa. Korisnici koji ne mogu pristupiti podacima jer je AD replikacija prestala raditi. Sve su to situacije koje se mogu izbjeći redovitim nadzorom.

Koje verzije Windows Servera podržavate?

Radimo sa svim aktivnim verzijama: Windows Server 2016, 2019 i 2022. Za starije sustave poput Server 2012 R2 možemo pomoći s migracijom na noviju verziju.

Radite li s virtualizacijom?

Da. Imamo iskustva s Hyper-V okruženjima koja su najčešća u hrvatskim tvrtkama. Postavljamo VM-ove, upravljamo resursima i planiramo kapacitet.

Koliko često trebam servisirati server?

Preporučujemo mjesečne provjere koje uključuju ažuriranja, pregled diskova i logova, test backupa i provjeru servisa. Za kritične sustave to može biti i češće.

Što ako server prestane raditi usred radnog dana?

Hitne situacije imaju prioritet. Cilj je prva reakcija unutar 30 minuta udaljenim pristupom. Ako je potreban dolazak na lokaciju, dogovaramo najbrži mogući termin.
